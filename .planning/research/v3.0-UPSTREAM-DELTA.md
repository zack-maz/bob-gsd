## Axis B — Bob Shell `1.0.x` → `2.0.1`

**Source:** `bob.ibm.com/docs/shell/*`, read 2026-08-13. Bob Shell **2.0.0** (August 2026) is a
major release: *"requires fresh installation with no automated upgrade from 1.0.x"*. **2.0.1**
followed with refinements and security fixes.

## Standing constraint that CHANGED

Every prior milestone was built under: *"No local Bob for testing — IBM Bob is not available on the
development device and won't be."* **This no longer holds** — a live Bob Shell 2.x install is
available for v3.0. The test-deferred model becomes empirical: the long-deferred acceptance pass can
run for real, and doc-derived conservative defaults (B1, B6, B7) can be settled by observation.
